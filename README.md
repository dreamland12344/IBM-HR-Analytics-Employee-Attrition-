# IBM HR Analytics – Employee Attrition Analysis Using SQL

## 📌 Project Overview
This project analyzes employee attrition using SQL to identify key factors associated with employee turnover. The analysis focuses on department, overtime, job satisfaction, and monthly income to generate insights that support data-driven HR decisions.

## 🎯 Objectives
- Analyze employee attrition across departments.
- Evaluate the relationship between overtime and attrition.
- Examine attrition across job satisfaction levels.
- Investigate attrition patterns across monthly income groups.
- Provide recommendations to improve employee retention.

## 📊 Dataset Overview
- Total Employees: 1,470
- Original Columns: 35
- Target Variable: Attrition
- Dataset: IBM HR Employee Attrition

## 🛠️ Tools & Technologies
- SQL
- SQL aggregate functions
- GROUP BY and ORDER BY
- CASE WHEN statements
- Data Cleaning and Exploratory Data Analysis

## 🔍 Key Insights
- Sales recorded the highest departmental attrition rate at 21%.
- Employees working overtime had a reported attrition rate of 31%, compared with 10% for those not working overtime.
- Employees with job satisfaction level 1 had the highest reported attrition rate at 23%.
- The lowest monthly income group had a reported attrition rate of 20%.

## 💡 Business Recommendations
- Improve employee retention in the Sales department.
- Review overtime policies and workload distribution.
- Enhance employee satisfaction and engagement.
- Review compensation and career growth opportunities.
